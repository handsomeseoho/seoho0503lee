# Minecraft Dino Add-on Project

마인크래프트 디노 애드온 프로젝트

## 파일 설명

- `CustomModel.bbmodel` - Blockbench 3D 모델 파일
- `CustomModel.java` - 커스텀 모델 Java 코드
- `T-REX.png` - 티라노사우루스 텍스처 이미지

## 프로젝트 개요

이 프로젝트는 마인크래프트에서 공룡(디노) 커스텀 모델을 추가하는 애드온입니다.

## Blockbench 사용법

### 기본 단계

1. **프로젝트 열기**
   - Blockbench 실행
   - `File` > `Open` 메뉴 클릭
   - `CustomModel.bbmodel` 파일 선택

2. **모델 수정**
   - 왼쪽 패널에서 큐브(부품) 선택
   - 3D 뷰에서 큐브 선택 및 이동/회전/크기 조절
   - 우측 패널에서 큐브 속성(이름, 위치, 크기) 수정

3. **텍스처 적용**
   - `File` > `Import` > `Texture` 메뉴 클릭
   - `T-REX.png` 파일 선택
   - 큐브에 텍스처 드래그 앤 드롭

4. **내보내기**
   - Java 코드 내보내기: `File` > `Export` > `Export Java Block/Item`
   - 모델 저장: `File` > `Save`

### 자주 쓰는 단축키

- `G` - 이동 모드
- `R` - 회전 모드
- `S` - 크기 조절 모드
- `T` - 텍스처 편집
- `Ctrl+Z` - 실행 취소
- `Ctrl+Y` - 다시 실행
