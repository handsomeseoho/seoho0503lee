# 마인크래프트 오토 클리커

마인크래프트에서 화면 중심 및 주변에 엄청 빠른 속도로 좌클릭하는 Python 프로그램입니다.

## 기능

- **F8**: 현재 마우스 위치에서 초고속 좌클릭 (근접 공격/채굴)
- **F9**: 현재 마우스 위치에서 우클릭 연타 (돌풍구, 물약 등)
- **F10**: 우클릭 꾹 눌렀다 떼기 (활, 삼지창)
- **F12**: 우클릭 꾹 눌러 장전 후 발사 (쇠내)
- 마우스를 누르고 있는 방식으로 마인크래프트 최적화
- 핫키로 프로그램 제어
- 매우 빠른 공격/채굴 속도

## 요구사항

- Python 3.x
- 다음 라이브러리들:
  - `pyautogui`
  - `keyboard`

## 설치

```bash
pip install pyautogui keyboard
```

## 사용법

1. 프로그램 실행:
```bash
python minecraft_auto_miner.py
```

2. 마인크래프트에서 사용할 대상에 마우스를 올립니다

3. 근접 공격/채굴 (검, 도끼 등):
   - `F8` 키를 누르면 좌클릭이 시작/정지됩니다
   - 마우스가 현재 위치에서 계속 좌클릭합니다
   - 다시 F8을 누르면 클릭이 중지됩니다

4. 원거리 무기 연타 (돌풍구, 물약 등):
   - `F9` 키를 누르면 우클릭 연타가 시작/정지됩니다
   - 마우스가 현재 위치에서 계속 우클릭합니다
   - 다시 F9를 누르면 클릭이 중지됩니다

5. 활/삼지창 (charge 후 release):
   - `F10` 키를 누르면 활/삼지창 자동 발사가 시작/정지됩니다
   - 우클릭을 꾹 눌렀다가 떼서 발사합니다
   - 다시 F10을 누르면 중지됩니다

6. 쇠내 (장전 후 발사):
   - `F12` 키를 누르면 쇠내 자동 발사가 시작/정지됩니다
   - 우클릭을 꾹 눌러 장전, 그 후 우클릭으로 발사합니다
   - 다시 F12를 누르면 중지됩니다

7. 프로그램 종료:
   - `ESC` 키 또는 `Ctrl+C`로 프로그램을 종료합니다

## 핫키

- **F8**: 근접 공격/채굴 시작/정지 토글 (좌클릭)
- **F9**: 원거리 무기 연타 시작/정지 토글 (우클릭)
- **F10**: 활/삼지창 시작/정지 토글 (우클릭 꾹 눌렀다 떼기)
- **F12**: 쇠내 시작/정지 토글 (우클릭 꾹 눌러 장전 후 발사)
- **ESC**: 프로그램 종료

## 설정

- `click_delay`: 근접 공격/채굴 클릭 딜레이 (기본값: 0.02초)
  - 낮출수록 클릭 속도가 빨라집니다
  - 너무 낮으면 마인크래프트에서 인식하지 못할 수 있습니다
- `ranged_delay`: 원거리 무기 연타 딜레이 (기본값: 0.1초)
  - 돌풍구, 물약 등의 발사 속도에 맞춰 조절하세요
- `charge_time`: 활/삼지창 차지 시간 (기본값: 1.0초)
  - 우클릭을 꾹 누르는 시간
  - 활의 풀차지 시간에 맞춰 조절하세요
- `reload_time`: 쇠내 장전 시간 (기본값: 1.5초)
  - 쇠내 장전에 필요한 시간
  - 쇠내 종류에 따라 조절하세요

## 주의사항

- 프로그램 사용 중에는 마우스와 키보드를 자유롭게 사용할 수 없습니다
- 마인크래프트 창이 활성화되어 있어야 정상적으로 작동합니다
- 매우 빠른 클릭 속도로 인해 서버에서 킥당할 수 있습니다
- 클릭 속도는 `click_delay` 값으로 조절하세요
- PVP 서버에서 사용할 경우 밴 위험이 있습니다

## 작동 원리

1. 사용자가 마우스를 사용할 대상에 올립니다
2. F8을 누르면 현재 마우스 위치에서 좌클릭(mouseDown/mouseUp)을 반복 (근접 공격/채굴)
3. F9를 누르면 현재 마우스 위치에서 우클릭(mouseDown/mouseUp)을 반복 (돌풍구, 물약 등)
4. F10을 누르면 우클릭 꾹 눌렀다 떼서 발사 반복 (활, 삼지창)
5. F12를 누르면 우클릭 꾹 눌러 장전 후 우클릭 발사 반복 (쇠내)
6. 다시 해당 키를 누르면 마우스를 떼고 클릭을 중지
