# 한국어 STT 및 마인크래프트 음성 채팅 프로그램

이 프로젝트는 두 가지 프로그램을 포함합니다:
1. **stt_korean.py** - 기본 한국어 음성 인식 프로그램
2. **minecraft_voice_chat.py** - 마인크래프트 베드락용 음성 채팅 프로그램

## 공통 설치 방법

필요한 패키지 설치:
```bash
pip install -r requirements.txt
```

---

## 1. 기본 한국어 STT 프로그램 (stt_korean.py)

Google Web Speech API를 사용한 무료 한국어 실시간 음성 인식 프로그램입니다.

### 사용 방법
```bash
python stt_korean.py
```

### 특징
- 완전 무료 (API 키 불필요)
- 실시간 음성 인식
- 한국어 지원
- 간단한 사용

---

## 2. 마인크래프트 베드락 음성 채팅 (minecraft_voice_chat.py)

마인크래프트 베드락 에디션용 음성 채팅 프로그램입니다. F10 키를 누르고 있으면 음성을 녹음하고, 떼면 텍스트로 변환하여 채팅창에 입력합니다.

### 사용 방법
```bash
python minecraft_voice_chat.py
```

### 작동 방식
1. 마인크래프트 베드락 에디션 실행
2. 마인크래프트에서 **채팅창 열기** (T 키)
3. **F10 키를 누르고 있으면** 녹음 시작
4. 말하기
5. **F10 키를 떼면** 텍스트 변환 및 자동 입력
6. **Enter 키**로 채팅 전송
7. 프로그램 종료: `Ctrl+C`

### 특징
- 완전 무료 (API 키 불필요)
- F10 키 길게 누르기로 직관적인 음성 녹음
- 한국어 지원
- 클립보드 사용으로 한글 입력 지원
- 게임 중 사용 가능

### 마인크래프트용 요구사항
- 마인크래프트 베드락 에디션
- 마인크래프트가 활성 창이어야 함
- 사용자가 직접 채팅창을 열어야 함

---

## 공통 요구사항

- Python 3.8+
- 마이크 (내장 또는 외장)
- **인터넷 연결**: Google Web Speech API 사용을 위해 필요
- PortAudio (pyaudio 의존성):
  - Windows: 자동 설치됨
  - Mac: `brew install portaudio`
  - Linux: `sudo apt install portaudio19-dev`

## 주의사항

- 인터넷 연결이 필수입니다
- 네트워크 상태에 따라 응답 속도가 달라질 수 있습니다
- 무료 사용량 제한이 있을 수 있습니다 (Google 정책에 따름)
- 마인크래프트용: F10 키는 마인크래프트에서 일반적으로 사용되지 않으므로 충돌 가능성이 낮음
- 마인크래프트에서 F10 키를 다른 용도로 사용하는 경우 키 설정을 변경해야 할 수 있음
