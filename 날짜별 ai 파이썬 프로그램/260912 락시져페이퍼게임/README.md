# 가위바위보 게임

파이썬 tkinter로 만든 GUI 가위바위보 게임입니다.

## 기능

- GUI 인터페이스로 버튼 클릭으로 게임 진행
- 사용자가 가위, 바위, 보 중 하나를 버튼으로 선택
- 컴퓨터가 랜덤으로 선택
- 승패 판정 및 결과 실시간 표시
- 게임 반복 실행 가능

## 실행 방법

```bash
python rps_game_gui.py
```

## 사용법

1. 프로그램을 실행합니다.
2. "가위", "바위", "보" 버튼 중 하나를 클릭합니다.
3. 사용자의 선택과 컴퓨터의 선택이 표시됩니다.
4. 게임 결과(승리/패배/무승부)가 표시됩니다.
5. 게임을 계속하려면 다시 버튼을 클릭합니다.

## 규칙

- 가위 > 보
- 바위 > 가위  
- 보 > 바위
- 같은 선택이면 무승부
