# 가위바위보 게임

파이썬으로 만든 간단한 가위바위보 게임입니다.

## 기능

- 사용자가 가위, 바위, 보 중 하나를 선택
- 컴퓨터가 랜덤으로 선택
- 승패 판정 및 결과 출력
- 게임 반복 실행 ('q' 입력 시 종료)

## 실행 방법

```bash
python rps_game.py
```

## 사용법

1. 프로그램을 실행합니다.
2. "가위", "바위", "보" 중 하나를 입력합니다.
3. 컴퓨터의 선택과 결과가 표시됩니다.
4. 게임을 계속하려면 다시 선택을 입력합니다.
5. 게임을 종료하려면 'q'를 입력합니다.

## 규칙

- 가위 > 보
- 바위 > 가위  
- 보 > 바위
- 같은 선택이면 무승부

## 파일

- `rps_game.py`: 가위바위보 게임 메인 프로그램
